# Dokumentasi Database Supabase -- Course Explorer

## Tahap 11: Membuat Tabel Database

### 1. Tujuan

Tahap ini menyiapkan database Supabase sebagai tempat penyimpanan data
mata kuliah pada aplikasi Course Explorer. Database menggunakan
PostgreSQL yang dikelola melalui Supabase.

### 2. Nama Tabel

-   **Schema:** `public`
-   **Nama tabel:** `courses`
-   **Deskripsi:** Menyimpan data mata kuliah Course Explorer.

### 3. Struktur Tabel

  ------------------------------------------------------------------------
  Nama Kolom        Tipe Data          Pengaturan        Keterangan
  ----------------- ------------------ ----------------- -----------------
  `id`              `bigint (int8)`    Primary Key,      ID otomatis untuk
                                       Identity, NOT     setiap mata
                                       NULL              kuliah

  `code`            `text`             NOT NULL, UNIQUE  Kode mata kuliah

  `title`           `text`             NOT NULL          Nama atau judul
                                                         mata kuliah

  `credits`         `integer (int4)`   NOT NULL, CHECK   Jumlah SKS
                                       lebih dari 0      

  `status`          `text`             NOT NULL, default Status mata
                                       `planned`         kuliah

  `created_at`      `timestamptz`      NOT NULL, default Waktu data dibuat
                                       `now()`           
  ------------------------------------------------------------------------

### 4. SQL Pembuatan Tabel

SQL berikut digunakan sebagai dokumentasi struktur tabel. Jalankan hanya
jika tabel `public.courses` belum dibuat.

``` sql
CREATE TABLE public.courses (
    id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    code text NOT NULL UNIQUE,
    title text NOT NULL,
    credits integer NOT NULL CHECK (credits > 0),
    status text NOT NULL DEFAULT 'planned',
    created_at timestamptz NOT NULL DEFAULT now()
);
```

### 5. Pengaturan Keamanan

Row Level Security (RLS) digunakan untuk mengatur hak akses terhadap
data. Status RLS dan kebijakan akses perlu diperiksa langsung pada
Supabase Dashboard. Jangan menonaktifkan RLS atau membuat akses publik
tanpa mempertimbangkan kebutuhan keamanan aplikasi.

Pada tahap ini, operasi CRUD melalui Supabase belum diimplementasikan.
Kebijakan akses untuk membaca dan mengubah data akan disesuaikan pada
tahap integrasi berikutnya.

### 6. Data Awal

Tabel dapat diisi menggunakan fitur **Import data from CSV** di Supabase
Table Editor. File CSV contoh menggunakan kolom `code`, `title`,
`credits`, dan `status`. Kolom `id` dan `created_at` tidak disertakan
karena nilainya dibuat otomatis oleh database.

### 7. Hasil dan Temuan

Tabel `courses` disiapkan dengan kolom yang dibutuhkan aplikasi Course
Explorer. Penggunaan primary key dan identity memudahkan pemberian ID
secara otomatis, sedangkan aturan NOT NULL dan UNIQUE membantu menjaga
konsistensi data. Kolom `created_at` digunakan untuk mencatat waktu
pembuatan data. RLS menjadi bagian penting untuk mengatur akses terhadap
database.
